### 🌸 whoami

<img src="https://github.githubassets.com/images/icons/emoji/unicode/1f338.png" align="right" width="80" hspace="28" vspace="10"/>

Estudante de Sistemas de Informação e desenvolvedora backend, focada em construir sistemas bem estruturados para melhor desempenho e aplicar a modelagem do banco à arquitetura da API. Atualmente estou desenvolvendo versionamento para um **LIMS (Laboratory Information Management System)** nos projetos de Extensão do SENAC, aplicando MVC, usando o Framework Spring Boot na linguagem Java. Continuo aprimorando projetos pessoais aplicando outras ferramentas web [nuxt e vue] e explorando novas forma de desenvolvimento do backend [Bun e Gin] 

<br>

Gosto de entender o *porquê* das decisões de arquitetura antes de escrever código, e trago essa mesma lógica para o front-end, priorizando componentes reutilizáveis e organização clara entre lógica reativa e estática.
